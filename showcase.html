Purchase Digest Agent

An AI agent that reads my inbox, writes me a summary, and cleans everything up — automatically.

✉ Gmail ◆ Slack ✦ Claude AI ⸻ Python

Section 01

What It Does

One command kicks off four steps, all handled by the agent without any manual work.

1
Search
Scans Gmail for receipts, order confirmations, and invoices that are older than 30 days — up to 100 threads at a time.
2
Summarize
Groups the emails by vendor or sender and counts how many came from each one.
3
Notify
Sends me a direct Slack message with a clean, formatted digest — total count, vendor breakdown, date range.
4
Archive
Moves every processed thread out of the inbox into a “Purchase Digest / Processed” folder for safe keeping.
Search Gmail → Group by vendor → Send Slack DM → File away

No email is deleted — just neatly filed away.

Section 02

What I’m Learning: Managed Agents

This project uses Anthropic’s Managed Agents SDK — a way to deploy AI agents that run in the cloud and call tools on demand. Here’s what I’m building fluency with right now.

📄
Defining an Agent

Writing the agent’s job description: what it knows, what its goals are, and what tools it’s allowed to use.

For the coders
YAML file with system prompt + tool schemas — deployed once, reused every run.
🔄
Custom Tool Loop

The agent lives in the cloud but it can’t touch my Gmail or Slack directly. So it asks my laptop to do those things and waits for the answer.

For the coders
Event stream → intercept tool call → execute locally → return result → repeat.
📶
Sessions & Streaming

The agent and my script stay in a live back-and-forth conversation until all the work is done — like a real-time phone call between them.

For the coders
sessions.create() opens the call — events.stream() keeps it alive.
🔒
Credential Split

My passwords and API keys never leave my machine. The AI handles the thinking; my laptop handles anything that needs a secret.

For the coders
Gmail OAuth token + Slack bot token stay local. Agent never sees them.

Section 03

What’s Next — Growing with Managed Agents

Each version adds one new capability. The goal is building confidence, not complexity.

Version 2
Remote Triggering

Right now I have to run a script on my laptop to kick things off. The next step is setting up a schedule so the agent wakes up on its own — no laptop required.

New skill: triggering an agent remotely via a cron schedule or webhook.

Version 3
Memory Across Runs

Today the agent starts fresh every time. A future version will remember what it already processed, so the digest gets smarter and avoids surfacing the same emails twice.

New skill: giving an agent persistent memory between sessions.

Version 4
Richer Workflows

Once the basics are solid: spending trends, category breakdowns, maybe a budget alert when a vendor’s total crosses a threshold.

New skill: multi-step reasoning with conditional logic and richer output formats.

One new thing at a time. Each version of this project teaches one new Managed Agents concept — then I move on. That’s the whole strategy.
